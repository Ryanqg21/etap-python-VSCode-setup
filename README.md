# ETAP Python Automation

Projects to automate power system studies in ETAP 24 using Python.

| # | Project | Description |
| - | ------- | ----------- |
| 1 | [ConectEtap](1.ConectEtap) | Connecting ETAP 24 to VS Code with the Python API and a virtual environment |
| 2 | CortoCircuito | Short-circuit studies from Python *(coming soon)* |

## How the repository is organized

Each project lives in its own numbered folder with its own README and step-by-step instructions. All projects share one virtual environment (`.venv`) in the repository root, so run commands from this folder.
